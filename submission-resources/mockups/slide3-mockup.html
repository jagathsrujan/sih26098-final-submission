technologies used

  • Sensing: GNSS + IMU + baro + ring angle (pickoff + magnetometer)
  • Power: three-phase rectification + four-quadrant stage · supercapacitor buffer · 180 V bus
  • Setting: the existing AOP-22 inductive chain — mode, ToF, target, MV, met
  • Build tools: FreeCAD CAD (gate-checked) · embedded C · 7-DOF simulation · HIL · dynamometer rig
methodology and process of implementation
  • IPP guidance — propagate → compare → command ring angle — credited to published work
  • Ours in the loop: the state-dependent authority gate + error-estimator integration
  • The ring is the inertial platform — ours to prove; the bench programme is tasked with proving it
  • Span-capped canard ring: resonance is an open item — evidence closes in the 7-DOF campaign
  • Process: 7-DOF Monte Carlo with guidance in the loop → HIL → rotating dynamometer rig (plan, not an asset) → integration demonstrator
  • GNSS-denied: coast on inertial to the drift limit (outage tolerance set in the campaign); anti-jam GNSS is a module-level substitution
