# Taste
- Prefers to complete multi-artifact work sequentially one item at a time in dependency/quick-win order, confirming each as done before requesting the next. Confidence: 0.9
- Prefers reusable, copy-paste prompts to carry work into a new session. Confidence: 0.8
- Runs multiple AI tools (e.g. Codex) in parallel on the same workspace and asks for self-contained, paste-ready handoff prompts to drive the other tool — the prompt must name the exact files to read first, the hard rules, and a validation step, and work with no chat context. Confidence: 0.75
- Wants generated slide content checked visually before hand-building in Figma: as a routine step after each slide round, asks for an image mockup (rendered slide preview, e.g. 1280×720 HTML+PNG) produced from the text/wireframe/figure specs — including having any diagram drawn from its node/edge spec into the mockup. Confidence: 0.8
- Delegates broad, multi-repo/workspace exploration to parallel subagents (explore-type) rather than one serial read-through, and explicitly names the model for them; briefs them with depth labels and tight read budgets. Confidence: 0.75
- When asking for exploration of prior work, wants the understanding persisted as written markdown notes files in the workspace (not just a chat summary), and keeps a running step/decision log in the workspace so a fresh session resumes cleanly. Confidence: 0.75
- Reserves a dedicated workspace for resources/reference material only, keeping it clean and separate from working/design repos (nothing copied in). Confidence: 0.6
- Favors `deepseek/deepseek-v4.1-flash` for subagent/exploration (research/file-reading) work, stated explicitly as the subagent model. Confidence: 0.7
- Picks the primary/session model explicitly and separately from subagent models (e.g. sets the session to "MiMo V2.6 Pro" / `xiaomi/mimo-v2.6-pro` with deepseek-flash subagents). Confidence: 0.6
- When a companion AI tool refuses a handoff prompt on defense-adjacent content, wants the prompt rewritten to pre-empt the refusal rather than accepting it: frame the job up front as graphic design/typesetting of already-final quoted submission strings (zero authoring, analysis or engineering decisions) for a student hackathon, state the inert/no-energetics context, tell the tool to treat technical strings as quoted material being set, and include a two-pass fallback (build the empty frame first, then typeset the verbatim strings). When a reframed prompt is refused again, he pastes the new refusal back expecting another fix attempt rather than abandoning the companion tool. Confidence: 0.85
- Prefers to hand-build final presentation decks himself rather than take an AI-generated/HTML deck as-is ("the deck I don't really like, I will make it manually later"). Confidence: 0.7
- Prefers an interactive "question me" session — wants the agent to ask him to decide the open design/framing choices (ideally offering a recommended option per question) and log the answers before generating the deliverables, rather than the agent deciding and building unilaterally — but only for decisions that are genuinely his (options + a recommendation); otherwise expects the agent to decide and draft. Confidence: 0.7
- Dislikes one-shot bulk generation: even when content is complete, rejects building every deliverable "all at one go" and wants work produced incrementally, staged in interactive rounds with him in the loop. Confidence: 0.75
- Wants answers grounded in already-published research/results rather than fresh re-derivation — asks the agent to mine the project's research papers (as the proven source of truth) to answer both current and future questions. Confidence: 0.7
- Prefers technical concepts explained in plain, non-specialist language (with analogies); flags "didn't understand" when answers are too technical and expects a simpler re-explanation rather than more depth. Confidence: 0.6
- Values his own understanding/ownership of the work over the finished artifacts — wants the agent to run teaching-style walkthroughs (one aspect per sitting: what was decided, why, what was rejected, what's still open) and have him explain it back / answer questions so he can then recommend improvements, rather than just handing him outputs. Confidence: 0.8
- Works through multi-part material at his own fast pace — signals progress with short directives ("next", "go") and likes the agent to end each step with an explicit "say go" checkpoint; prefers to defer detailed comprehension checks / Q&A to one consolidated round at the end rather than pausing to verify each part inline. Confidence: 0.7
- Deliberately avoids finishing the full/final design prematurely and holds back non-essential extras in a "freedom ledger" so later rounds keep room to add novelty. Confidence: 0.85
- Scopes a session or phase to a single goal (e.g. submission texts only — no CAD, no deck production) instead of running two workstreams at once; found doing full design + submission simultaneously inefficient. Confidence: 0.7
- Heavy-reading budget discipline (imposed on subagents and followed directly): never gulp a file >100 KB — check size first and window it; never read images or PDFs; use grep + small line windows on large registers instead of wholesale reads; never re-read research papers wholesale when a project digest exists. Confidence: 0.8
- Non-negotiable claim discipline for written outputs: nothing unruled or provisional prints as fact; derived-not-asserted; margins stated as margins; every number carries status + source + closer, using a three-part format for weak numbers (value → status/source → what closes it); on slides the honesty wording prints inline, attached to its number — never a detachable status strip. Confidence: 0.9
- Declares an explicit source-authority order for conflicting facts (authoritative design register ≻ raw evidence (CAD/atlas/sim) ≻ working notes) rather than deciding ad hoc. Confidence: 0.75
- Treats declared read-only truth repos as immutable — proposes patches for their owner instead of editing them directly. Confidence: 0.8
- Insists claims cite-and-credit their lineage (fielded kit, patents, literature) and flags an unread or uncited source as a defect to fix before citing it. Confidence: 0.8
- Wants final texts delivered paste-ready and character-counted against hard limits, with live character math while drafting and a designated "trim bank" to fund overflows. Confidence: 0.7
